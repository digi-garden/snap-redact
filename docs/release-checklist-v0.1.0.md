## 1. 準備

### 1.1 ブラウザ

| ブラウザ | 環境 | 範囲 |
| :--- | :--- | :--- |
| Chrome 最新版 | Windows（手元） | 3章の全項目 |
| Edge 最新版 | Windows（手元） | 3章の全項目 |

* 各ブラウザで、拡張機能を切ったウィンドウ（シークレット／InPrivate／プライベート）で確かめる。拡張機能が CSP の違反やエラーを出すことがあるため
* 確認の前に、ブラウザのバージョンを 5章に書く

### 1.2 テスト画像

`snap-redact-test-images.zip`（S13 で Claude が作成）を展開して使う。どれも架空のデータで作っている。

| ファイル | 使う項目 | 内容 |
| :--- | :--- | :--- |
| `01-transparent-text.png` | MT-11、MT-16 | 背景が透明で、黒と赤の文字がある PNG |
| `02-unsupported.bmp` | MT-05 | 非対応の形式（BMP） |
| `03-animated.gif` | MT-07 | 3コマのアニメーション GIF（最初のコマは赤） |
| `04-gps.jpg` | MT-19 | 位置情報（GPS）と機種名を EXIF に入れた JPEG |
| `05-too-wide-16385px.png` | MT-06 | 長辺 16,385px（上限を 1px 超える） |
| `06-max-16384px.png` | MT-06 | 長辺 16,384px（上限ちょうど。読み込める） |
| `07-tall-1920x12000.png` | MT-06 | 縦長のフルページスクショに相当する画像 |

スクリーンショット（MT-01 など）は、その場で撮ったものを使う。社内の画面など本物の機密が写ったものは使わない。

| MT-15〜17、19、20 | P5（利用者が手で確認） | OK |
| MT-18 | E2E（ファイル名・画素・メタデータのチャンク） | OK |

## 3. チェック表

「Safari」列の `●` は、iPad・iPhone で確かめる項目。空欄は対象外（`―` を書く）。

| ID | 確認内容 | 手順・合格条件 | Chrome | Edge | Firefox | Safari |
| :--- | :--- | :--- | :---: | :---: | :---: | :---: |
| MT-01 | 貼り付け | スクショを撮り、ページで `Ctrl+V`（`⌘V`）→ 表示される | | | | ● |
| MT-02 | Web 上の画像の貼り付け | 別のタブで Web ページの画像を右クリック → 画像をコピー → `Ctrl+V` で表示される | | | | ● |
| MT-03 | ドロップ | 画像ファイルを、キャンバスの上と外（ヘッダーの上など）の両方に落とす → どちらも読み込め、ページを離れない | | | | |
| MT-04 | ファイル選択 | 「画像を選択」で同じファイルを2回続けて選ぶ → 2回とも読み込める（2回目は差し替え） | | | | ● |
| MT-05 | 非対応の入力 | 文字だけをコピーして `Ctrl+V` → TS-01「画像が見つかりませんでした」。`02-unsupported.bmp` を落とす → TS-02 | | | | |
| MT-06 | 大きな画像 | `07-tall-1920x12000.png` が読め、黒塗りできる。`06-max-16384px.png` が読める。`05-too-wide-16385px.png` で TS-04 が出て、ブラウザが固まらない | | | | ● |
| MT-07 | GIF | `03-animated.gif` で赤い最初のコマが表示され、TS-09 が出る | | | | |
| MT-08 | 黒塗りの端 | 縮小表示のまま文字を黒塗り → ダウンロード → 画像ビューアーで拡大し、黒の境界に中間色がなく、文字がはみ出していない | | | | |
| MT-09 | 細い矩形 | 高さ 2px ほどの横長の範囲を黒塗りできる | | | | |
| MT-10 | モザイク | `M` でモザイク。ブロックが大きく文字が読めない。注意文（NT-01）が出る | | | | ● |
| MT-11 | 透過画像のモザイク | `01-transparent-text.png` の文字にモザイク → ダウンロード → 白・黒の背景で見ても文字が透けない（Windows のフォトで背景を変える、または PowerPoint に貼って背景色を変える） | | | | |
| MT-12 | 元に戻す・クリア | 3件操作して `Ctrl+Z` で1件ずつ戻る。ボタンでも戻る。クリアで最初の画面に戻る | | | | ● |
| MT-13 | ドラッグ中の操作 | ドラッグしたまま `Ctrl+V`・`Ctrl+C`・`B` を押しても何も起きない。`Esc` で選択枠が消える | | | | |
| MT-14 | 性能 | 4K のスクショで 20 回ほど黒塗り・モザイク → `Ctrl+Z` を続けて押しても引っかからない | | | | |
| MT-15 | コピー | ボタンと `Ctrl+C`（`⌘C`）でコピーでき、TS-06 が出る | | | | ● |
| MT-16 | 貼り付け先 | コピーした画像を Slack と Qiita のエディタに貼れる。`01-transparent-text.png` を加工したものも貼れる | | | | ● |
| MT-17 | 文字のコピーを邪魔しない | 下部の説明の文字を選んで `Ctrl+C` → 文字がコピーされる（画像はコピーされない） | | | | |
| MT-18 | ダウンロード | `redacted_image.png` で保存され、TS-08 が出る | | | | ● |
| MT-19 | メタデータ | `04-gps.jpg` を読み込んでダウンロード → 保存した PNG のプロパティ（エクスプローラーで右クリック → プロパティ → 詳細）に GPS・カメラの情報がない。元の `04-gps.jpg` には緯度・経度が出ることも確かめる | | | | |
| MT-20 | 差し替えの確認 | コピーした後に次の画像を貼る → 確認なしで差し替わる。コピーせずに編集してから貼る → DL-01 が出る。キャンセルで元の画像が残る | | | | ● |
| MT-21 | 外部通信 | DevTools の Network を開いたまま、貼り付け → 黒塗り → モザイク → コピー → ダウンロード → ページ本体（HTML・JS・CSS・ファビコン）以外の通信がない | | | | |
| MT-22 | CSP | Network でページ本体を選び、Response Headers に `content-security-policy` があり `connect-src 'none'` を含む。Console で `fetch('https://example.com')` がブロックされる | | | | |
| MT-23 | CSP 違反のエラー | 通常の操作の間、Console に CSP 違反などのエラーが出ない | | | | |
| MT-24 | 確認ダイアログ | 右上のバッジと、フッターの「安全性とプライバシー」の両方から DL-02 が開く。手順どおりに確かめられる | | | | ● |
| MT-24-2 | ダイアログ表示中の入力 | DL-01・DL-02 の表示中に `Ctrl+V`・ドロップ・`Ctrl+C`・`B` をしても何も起きず、ドロップの強調表示も出ない | | | | |
| MT-25 | キーボード操作 | Tab でボタンを順に移動でき、フォーカスの輪が見える。ダイアログの中でフォーカスが閉じ込められ、閉じると元の場所に戻る | | | | |
| MT-26 | スマホ | 「PC 向けツールです」の案内が出る。画像の選択とダウンロードができる（スマホで確認） | ― | ― | ― | ● |
| MT-27 | ストレージ | 操作の後、DevTools の Application（Firefox は Storage）で、localStorage・sessionStorage・IndexedDB・Cache Storage に何もない | | | | |
| 追加-1 | ページ下部・フッター | 下部の説明とフッターが崩れず、リンクが別タブで開く。「OSSライセンス」で一覧が表示され、原文を開ける | | | | ● |

* MT-08・MT-11 の画素は、P4 と E2E で全数を確かめ済み。ここでは、見た目で異常がないかを確かめる
* MT-21〜23 は、公開後に公開 URL（`https://circle-note.com/snap-redact/`）でもう一度確かめる（4章）
