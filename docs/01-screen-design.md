## 2. メイン画面のレイアウト

```text
+-----------------------------------------------------------------------+
| [ロゴ] Snap-Redact  スクショを貼る前の5秒前処理   [🛡️ 外部通信ブロック中（CSP）] |  ヘッダー 56px
+-----------------------------------------------------------------------+
| [⬛ 黒塗り B][🏁 モザイク M] │ [↩ 元に戻す]                [🗑️ クリア] |  ツールバー 48px
| ⚠ 文字には黒塗りを推奨（モザイクは復元されうる）  ※モザイク選択中のみ   |  注意文 32px
+-----------------------------------------------------------------------+
|                                                                       |
|                         キャンバス領域（残り全部）                      |
|                                                                       |
+-----------------------------------------------------------------------+
| [📋 画像をコピー  Ctrl+C]                          [💾 ダウンロード]   |  アクションバー 64px
+-----------------------------------------------------------------------+
| テキストの機密を隠すなら → Mask & Unmask ｜ GitHub ｜ 免責文 ｜ © digi-garden |  フッター 40px
+-----------------------------------------------------------------------+
```

* 画面全体の高さはウィンドウの高さ（`100dvh`）に合わせ、ページ自体はスクロールさせない。キャンバス領域が残りの高さをすべて使う（UI-4）
* 横幅は制限しない（左右の余白 24px）
* 注意文の行はモザイク選択中だけ表示する。表示・非表示でキャンバス領域の高さが変わってよい

## 3. 各領域の詳細

### 3.1 ヘッダー

| 要素 | 内容 |
| :--- | :--- |
| ロゴ | `brand-assets` の CircleNote ロゴ（ビルド時に同梱）。クリックで `https://circle-note.com/` へ |
| 製品名 | 「Snap-Redact」 |
| サブタイトル | 「スクショを貼る前の5秒前処理」（幅 768px 未満では非表示） |
| バッジ | 「🛡️ 外部通信ブロック中（CSP）」。アクセントカラーの枠と文字。ボタンとして扱い、クリックで DL-02 を開く。ツールチップ「通信をブロックしている仕組みと確かめ方」 |

### 3.2 ツールバー

| 要素 | 種類 | 有効になる条件 | キー | 補足 |
| :--- | :--- | :--- | :--- | :--- |
| ⬛ 黒塗り | 切り替えボタン（2つで1組） | 常時 | `B` | 初期値。選択中はアクセントカラーで塗る。`aria-pressed` |
| 🏁 モザイク | 同上 | 常時 | `M` | 選択中は NT-01 を表示 |
| ↩ 元に戻す | ボタン | 操作が1件以上 | `Ctrl+Z` / `⌘Z` | ツールチップにキーを表示 |
| 🗑️ クリア | ボタン | 画像を読み込み済み、ドラッグ中でない | なし | 確認なしで初期画面に戻る（ED-8）。誤って押さないよう、**ツールバーの右端に離して置く** |

* 無効のボタンは文字色を `zinc-600` にし、クリックできないようにする（`disabled`）
* キーの表記は OS に合わせる（Mac は `⌘`、それ以外は `Ctrl`）

### 3.3 キャンバス領域

| 状態 | 表示 |
| :--- | :--- |
| 未読み込み | 中央に破線の枠（`zinc-700`）。枠内に次を表示する<br>・大きく「Ctrl+V でスクショを貼り付け」（Mac は「⌘V」）<br>・小さく「または画像をドロップ ／ [画像を選択]」<br>・最下部に小さく「画像はこのタブの中だけで処理され、送信も保存もされません」 |
| 読み込み済み | 画像を中央に配置し、領域に収まるよう縮小して表示する。**領域より小さい画像は拡大しない**（等倍のまま）。画像の上ではカーソルを十字（`crosshair`）にする |
| 透過のある画像 | 画像の背後に市松模様（`zinc-800` / `zinc-900`、8px）を敷き、透過部分がわかるようにする。出力には市松模様を含めない |
| ドラッグ中 | 選択枠を表示する：アクセントカラーの 2px 実線、内側は半透明（黒塗りは黒 40%、モザイクはアクセントカラー 15%）。枠の位置は整数化後の範囲に合わせる（ED-5）。**選択枠は Canvas に描かず、Canvas の上に重ねた要素（`pointer-events: none`）で表示する**ので、出力には混ざらない |
| ファイルを重ねている | 領域全体にアクセントカラーの破線枠と、中央に「ここにドロップ」を重ねる。キャンバス外に重ねても同じ表示にする（IN-2） |

* `<canvas>` 要素自体には `border` と `padding` を付けない（座標の変換がずれて、黒塗りの端から文字がはみ出すのを防ぐため）。枠線や影は外側の要素に付ける
* ドラッグ中は、貼り付け・ドロップ・ファイル選択を受け付けない

### 3.4 アクションバー

| 要素 | 種類 | 有効になる条件 | 補足 |
| :--- | :--- | :--- | :--- |
| 📋 画像をコピー | 主ボタン（アクセントカラーで塗る） | 画像を読み込み済み | ラベルの右にキー表記「Ctrl+C」（Mac は「⌘C」）を小さく添える |
| 💾 ダウンロード | 副ボタン（枠のみ） | 画像を読み込み済み | 保存名 `redacted_image.png` |

* 画像の大きさ（例：`1920 × 1080 px`）と操作の件数（例：`3 件`）を、アクションバーの中央に小さく表示する

## 4. ダイアログ

### 4.1 DL-01 差し替え確認（IN-5）

表示する条件：画像を表示中に新しい画像を受け取り、最後のコピー／ダウンロード以降に操作がある場合。

```text
┌─────────────────────────────────────────┐
│ 編集中の画像を差し替えますか？            │
│                                         │
│ コピーもダウンロードもしていない編集内容は  │
│ 破棄されます。                            │
│                                         │
│                [キャンセル] [差し替える]   │
└─────────────────────────────────────────┘
```

* 初期フォーカスは「キャンセル」（誤操作で編集を失わないため）
* `Esc` と背景クリックは「キャンセル」と同じ
* ダイアログ表示中の `Ctrl+V` は無視する

### 4.2 DL-02 確認手順（UI-2、柱A）

```text
┌──────────────────────────────────────────────────────────┐
│ 🛡️ 外部通信をブロックしている仕組み                         │
│                                                          │
│ このページは、ブラウザの仕組み（CSP: connect-src 'none'）で   │
│ 外部への通信を禁止しています。これは画面上の表示ではなく、     │
│ サーバーが返すレスポンスヘッダーによる設定です。               │
│ 画像はこのタブのメモリ上でだけ処理され、どこにも送信・保存     │
│ されません。                                              │
│                                                          │
│ 自分で確かめる方法                                          │
│ 1. F12 で DevTools を開き、Network タブを表示する            │
│ 2. 画像を貼り付けて黒塗りし、コピーする                       │
│ 3. ページ本体の読み込み以外に通信がないことを確認する          │
│ 4. Console で fetch('https://example.com') を実行すると、    │
│    CSP によりブロックされる                                  │
│ 5. Network タブでページ本体を選び、Response Headers の       │
│    Content-Security-Policy を確認する                       │
│                                                          │
│ ブラウザの拡張機能はページの内容を読めるため、この仕組みでは   │
│ 防げません。信頼できない拡張機能は無効にしてお使いください。   │
│                                                          │
│ ソースコード：github.com/digi-garden/snap-redact            │
│                                              [閉じる]     │
└──────────────────────────────────────────────────────────┘
```

* 手順 4 の `fetch(...)` はコードとして等幅で表示し、横に「コピー」ボタン（テキストをコピー）を置く
* `Esc`、背景クリック、「閉じる」で閉じる
* 拡張機能についての注意は、04 の 1.3（防げないもの）を利用者に正直に伝えるためのもの（S4 で追加）
* ブラウザ標準の `<dialog>`（`showModal`）を使い、背後の操作の無効化・フォーカスの閉じ込め・閉じた後のフォーカスの戻りはブラウザに任せる

## 8. スマホでの表示（UI-6）

* NT-02 をヘッダーの下に表示する（閉じると、そのタブを開いている間は再表示しない。保存はしない）
* サブタイトルを隠し、バッジは「通信ブロック中（CSP）」に短縮する。ツールバーは折り返して2行になってもよい
* ボタンの高さは 44px 以上にする（タッチしやすさ）。キー表記（B、M、Ctrl+C）は出さない
* 未読み込み時の案内は「[画像を選択]」ボタンを主にし、「Ctrl+V」の文言は出さない
* キャンバス上のドラッグはタッチでも動くようにする（`touch-action: none`）が、動作は保証しない

## 9. アクセシビリティ（最低限）

* すべてのボタンに文字ラベルを付ける（アイコンだけのボタンは作らない）
* モード切り替えは `aria-pressed` で状態を伝える
* ダイアログは `role="dialog"`、`aria-modal="true"`。開いている間はフォーカスをダイアログ内に閉じ込め、閉じたら元の位置に戻す
* キャンバスには `aria-label="編集中の画像"` を付ける

## 12. 画面モック

Design キャンバス「Snap-Redact 画面モック」に次の4枚を用意した。

| アートボード | 内容 |
| :--- | :--- |
| SC-01 未読み込み | 初期状態。ボタンの無効表示と空状態の案内 |
| SC-01 編集中 | 黒塗り2か所・モザイク1か所・ドラッグ中の選択枠・コピー成功のトースト。黒塗り／モザイクの切り替えは操作でき、モザイクにすると NT-01 が出る |
| DL-01 / DL-02 | 差し替え確認と確認手順のダイアログ |
| スマホ表示 | 幅 390px での表示（UI-6） |

* ロゴは仮（円のアイコン）。実装時に `brand-assets` のものに差し替える
